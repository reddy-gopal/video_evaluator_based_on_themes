# Quick Guide: Creating OAuth Credentials

## Step 1: Create `client_secret.json`

### 1.1. Go to Google Cloud Console
- Visit: https://console.cloud.google.com/
- Sign in with your Google account

### 1.2. Create or Select a Project
- Click the project dropdown at the top
- Click **"New Project"** (or select existing project)
- Enter project name: `Video Theme Matcher` (or any name)
- Click **"Create"**
- Wait for project creation, then select it

### 1.3. Enable Required APIs
- Go to **"APIs & Services"** > **"Library"**
- Search for **"Google Sheets API"** → Click it → Click **"Enable"**
- Search for **"Google Drive API"** → Click it → Click **"Enable"**

### 1.4. Configure OAuth Consent Screen
- Go to **"APIs & Services"** > **"OAuth consent screen"**
- Select **"External"** (or **"Internal"** if using Google Workspace)
- Click **"Create"**
- Fill in:
  - **App name**: `Video Theme Matcher` (or any name)
  - **User support email**: Your email
  - **Developer contact information**: Your email
- Click **"Save and Continue"**

### 1.5. Add Scopes
- On the **Scopes** page, click **"Add or Remove Scopes"**
- In the filter box, search and add:
  - `https://www.googleapis.com/auth/spreadsheets`
  - `https://www.googleapis.com/auth/drive.readonly`
- Click **"Update"**
- Click **"Save and Continue"**

### 1.6. Add Test Users (if app is in Testing mode)
- On the **Test users** page, click **"+ ADD USERS"**
- Add your Gmail address (the one you'll use to sign in)
- Click **"Add"**
- Click **"Save and Continue"**
- Click **"Back to Dashboard"**

### 1.7. Create OAuth Client ID
- Go to **"APIs & Services"** > **"Credentials"**
- Click **"+ CREATE CREDENTIALS"** at the top
- Select **"OAuth client ID"**
- If prompted about consent screen, click **"Configure consent screen"** and complete steps above
- Select **"Desktop app"** as Application type
- Enter name: `Video Theme Matcher Client` (or any name)
- Click **"Create"**

### 1.8. Download Credentials
- A popup will show your Client ID and Client Secret
- Click **"Download JSON"** button
- The file will be downloaded (usually named something like `client_secret_xxxxx.json`)

### 1.9. Rename and Place File
- Rename the downloaded file to: `client_secret.json`
- Move it to your project root directory (same folder as `index.py`)

**✅ Done! `client_secret.json` is ready.**

---

## Step 2: Create `token.json` (Automatic)

**You DON'T need to create `token.json` manually!**

### How it works:
1. Run the script: `python index.py`
2. A browser window will open automatically
3. Sign in with your **Gmail account** (the one that has access to the Drive files)
4. Click **"Allow"** to grant permissions
5. The script will automatically create `token.json` and save it in your project folder

### If you need to re-authorize:
- Delete `token.json` file
- Run the script again
- Sign in again when browser opens

**✅ That's it! The script handles `token.json` automatically.**

## Troubleshooting

### Error: "client_secret.json not found"
- Make sure you downloaded the JSON file from Google Cloud Console
- Rename it to exactly `client_secret.json` (not `client_secret_xxxxx.json`)
- Place it in the same folder as `index.py`

### Error: "OAuth consent denied"
- Make sure your email is added as a test user in OAuth consent screen
- Delete `token.json` and try again
- Make sure the app is not in "Testing" mode, or add your email to test users

### Error: "Invalid client"
- Verify `client_secret.json` is the correct file from Google Cloud Console
- Delete `token.json` and try again
- Make sure you selected "Desktop app" when creating OAuth client ID
